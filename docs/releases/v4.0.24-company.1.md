# CC Switch Company v4.0.24-company.1

## 更新内容

- 同步官方稳定版 v4.0.24，保留企业飞书认证、公司模型配置和企业更新入口。
- 刷新企业配置时继续删除 `supports_websockets = true`，不默认开启 WebSocket；保留显式设置的 `false`。
- 企业配置不再写入 `disable_response_storage`，刷新时清理旧的 `true` 或 `false` 值，交由 Codex 使用其默认行为。
- 对已验证的 `leharrt.com` / `gpt-5.6-sol` 路由添加远程压缩 V2 专用公司卡；原混合模型卡和当前选择不变，需主动选择名称带“远程压缩 V2”的卡才能使用这项能力。
- 公司配置刷新会清理旧 `features.remote_compaction_v2` 开关，保留其他 feature/capability；不将未验证的 Gemini、DeepSeek、GLM 路由标记为支持 V2。
- 默认开启 Codex 登录模式自动切换，支持公司渠道直连及本地代理聚合模式。
- 约每 5 分钟检查已登录的 ChatGPT 账号。确认额度耗尽且无可用 credits 后，临时使用聚合渠道的 API 登录模式；确认额度恢复后还原。
- 不删除或覆盖官方 `auth.json`，不替换聚合渠道的 API 凭据；刷新公司配置时保留仍有效的自动切换状态。
- macOS 在确认没有运行中的请求或任务后，尝试刷新 Codex 桌面后台的登录状态；刷新意图可以在 CC Switch 重启后继续处理。

## 使用边界

- CC Switch 需要保持运行，公司或第三方 API 渠道自身需要有效凭据和可用额度。本功能不增加官方额度，也不自动轮换其他渠道。
- 自动后台刷新当前仅支持 macOS。Windows 或无法安全确认后台状态时，会提示手动重启 Codex。
- 网络错误、过期登录及无法确认的额度响应不会触发错误切换；当前额度探测支持文件保存的官方登录，其他凭据存储方式不自动处理。
- 本功能没有用真实耗尽账号完成发送按钮解锁验收，不应把配置变更或后台退出提示当作已经发送成功的证明。
- 本次额度处理不强制开启 WebSocket，不修改 NewAPI、CPA 或网关的模型路由。
- 远程压缩已在桌面捆绑 Codex `0.166.0-alpha.5.1` 验证。实测旧引擎 `0.142.5` 和本机独立 `1.3.0` 忽略显式 V2 能力，仍使用普通摘要压缩；不承诺所有旧版本行为相同。
- V2 不依赖 WebSocket 或响应存储，不意味着每轮自动压缩；自动触发仍取决于模型窗口和阈值。用户上传的图片可能被保留，不承诺清除所有图片或解决全部延迟。
